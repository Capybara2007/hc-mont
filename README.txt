# KlimaServis — mobilni prototip

## Fajlovi
- `index.html` — struktura stranice i formular
- `style.css` — izgled, uključujući prilagođavanje telefonima
- `script.js` — mobilni meni, izbor usluge, datum i demo ponašanje forme

## Kako da pokreneš
1. Raspakuj ZIP.
2. Otvori `index.html` u pregledaču.
3. Za izmenu koristi Visual Studio Code ili drugi editor.

## Važno
Ovo je frontend prototip. Formular se trenutno NE šalje i ne čuva podatke. Za stvaran rad treba povezati Supabase bazu, dodati bezbednosna pravila i serversku funkciju za potvrde i godišnje imejl podsetnike. Nemoj objavljivati tajne ključeve u `script.js`.
